# 模型与 API 配置方案

> 状态：`计划`。资料访问日期：2026-11-14。本文记录用户提供的渠道报价/参考配额、公开资料核实结果、建议配置和待验证事项；不代表任何端点、账户或翻译质量已验收。
> 范围：模型与 API 选型方案及后续开发计划。2026-11-14 的后续实施已将有限正数 `API_TIMEOUT` 传入 OpenAI-compatible 聊天、Gemini 生成、RAG embedding 和章节对齐 embedding；该局部实现不构成通用 Provider 配置、数据授权或真实端点评估。本文所列建议仍未通过本项目样本评测。

## 证据与判断规则

- `用户输入`：用户提供的模型名称、人民币报价、配额和 DeepSeek 时段价格。保留原值；人民币报价以每百万 token（1M tokens）计，且为用户可用渠道报价。
- `公开事实`：截至资料访问日可由供应商公开资料核验的模型标识、公开用途、API 协议和配额规则。公开描述不是本项目样本上的质量证明。
- `建议`：依据当前流水线和用户报价提出的暂定配置，须经后续契约测试和翻译样本验收后才能成为默认。
- `未知/待验证`：账户配额、渠道实际路由/协议、响应 schema、服务可用性、质量、时延和实际账单，需在获批账户/端点中确认。
- 当前代码以环境变量/JSON 和 `pipeline.py` 配置为主；`TranslationPipeline` 在单一 Python 进程中顺序执行上下文标注、初译、校对、润色，并由 RAG 使用 Gemini embedding。仓库没有模型分配 UI 或通用多 Agent 调度运行时。事实依据见[架构与边界](architecture.md)、[翻译流程](translation-workflow.md)、[开发与验证](development.md)。

### 用户报价与公共标价边界

- 表中人民币价格只表示用户已确认的渠道报价，不是供应商官方人民币价。不得把公开美元价直接换算成渠道价，也不将缺少人民币价格的 Google 模型排序为更便宜或更贵。
- 对所给三组 OpenAI 渠道报价，若仅比较非缓存输入/输出单价，Luna 的单位价格最低；这只是单位价格事实，不是每章成本或质量性价比结论。
- DeepSeek 报价须区分峰时倍增。官方时区规则是 UTC 周一至周五时段；将用户时段解读为 UTC+8 是基于用户提供时段与官方时段相差八小时的对应推断。
- 单次任务成本取决于各阶段输入/输出 token、缓存读取/写入是否实际发生、峰谷时段、失败重试和备用调用。缓存写入不一定发生，也不能用“缓存读取单价”替代全部输入计费。
- 后续成本对比应同时报告费用和质量/人工后编辑结果；未完成同一批样本、同一提示词和相同上下文的对照前，不使用“性价比最高”作为已证实结论。

## 阶段与职责模型

下表将产品目标转成可配置职责，不表示当前代码已经拆成独立 Agent。阶段边界依据现行 `pipeline.py` 顺序及项目目标延展；保存/写知识等非生成步骤不必强行分配生成模型。

| 职责/阶段 | 工作边界 | 选择模型时的约束 |
| --- | --- | --- |
| 需求理解与任务规划 | 识别目标语言、文本类型、输出要求和数据边界，形成可执行章节任务 | 当前主要由 CLI 参数/项目约定提供；尚无独立规划 Agent。复杂决策可评估 Sol，常规整理可评估 Luna。 |
| 任务拆解与路由 | 按章节、阶段和异常类型安排任务/模型 | 工作流规则优先使用确定性代码；Decision 1 只适合固定选项判断，不代替调度状态机。 |
| 知识检索与嵌入 | 检索词条、剧情/人物背景、翻译记忆；必要时生成文本向量 | Embedding 模型与生成模型分开配置；检索命中需作为参考而非事实校验。 |
| 上下文标注 | 推断说话人、语境提示和歧义线索 | 适合轻量结构化生成；涉及人物关系/剧情冲突时需可升级至更强生成模型或人工复核。 |
| 初译 | 基于原文、已批准术语和上下文产出 1:1 段落译文 | 忠实原文优先；禁止润色阶段反向改变事实。模型结果尚无本项目对照评测。 |
| 逻辑/忠实度校对 | 对照原文审查漏译、误译、指代、因果、术语和人物声音，给出修改建议 | 高影响语义判断可升级模型；固定类别打分可单独评估 Decision 1，但不能代替文本解释和改写。 |
| 文风润色 | 在不损害“信、达”的前提下改善中文自然度和角色声音 | 可优先评估 Luna 的单位成本，Terra 作为写作向候选；须用人工评审确认不改写事实。 |
| 格式/质量门禁 | 验证段落数、schema、标点/引号、术语一致和知识状态 | 确定性规则应优先于模型；模型只辅助识别语义问题，不能放宽 Provider 内容拦截。 |
| 总结与错误分析 | 汇总章节处理结果、未决项、失败原因和费用/用量 | 简单结构化摘要可评估 Luna 或 Flash Lite；账单和错误分类以程序记录为准。 |

此表供未来配置界面展示“暂定推荐”；首选/备用表示候选顺序，不表示已部署、已连通或实测更优。能力类型、API 协议或数据授权不满足时必须显示不兼容，不得静默切换。

| 阶段/职责 | 暂定首选 | 暂定备用 | 选择理由与限制 |
| --- | --- | --- | --- |
| 需求理解/任务规划 | `gpt-6.1-sol`（复杂/高影响任务）；`gpt-6-luna`（常规任务） | `deepseek-flash` | Sol 的公开定位偏复杂推理，Luna 渠道价更低；DeepSeek 峰谷价及实际渠道协议需计入。项目尚无此 Agent。 |
| 任务拆解/固定选项路由 | 确定性工作流规则；需模型判断时评估 `Gemini Decision 1` | `Gemini 3.5 Flash Lite`（仅可生成解释时） | Decision 专用接口适合封闭选项，不适合开放式规划；备用模型不是同协议替换，必须有适配和错误分流。 |
| 知识检索/文本嵌入 | `Gemini Embedding 2` | 暂无可确认的同类备用模型 | 当前项目已采用此嵌入路线；候选失败时应降级到词面/非向量检索或停止相应检索，而不是调用文本生成模型伪造嵌入。 |
| 上下文标注 | `gpt-6-luna` | `deepseek-flash` | 常规结构化文本任务优先评估较低渠道单价选项；DeepSeek 是备选，但无质量或兼容性实测。 |
| 初译 | `gpt-6-luna`（暂定成本基线） | `deepseek-flash` | 依用户人民币渠道报价，Luna 的输入/输出单位价格在已报价生成模型中最低。忠实度无评测结论；默认启用前须先做同样本盲评。 |
| 逻辑/忠实度校对 | `gpt-6.1-sol`（高影响段落候选）；`gpt-6-luna`（一般段落候选） | `deepseek-flash` | 以“信”优先，复杂语义候选可给 Sol 更高优先级，但较高费用必须由漏译/误译检出收益证明。不是已验证质量排序。 |
| 文风润色 | `gpt-6-luna` | `gpt-6.1-Terra` | Luna 的单位报价低；Terra 的公开描述包含清晰自然写作。两者在中文轻小说润色上的实际差异未知。 |
| 固定类别质量标记 | `Gemini Decision 1`（仅在问题可封闭定义时） | `Gemini 3.5 Flash Lite` | Decision 不产生普通文本，不负责修订；Flash Lite 可返回解释，但价格/账户额度需核实。格式、schema、段落完整性仍由确定性校验负责。 |
| 总结/错误分析 | `gpt-6-luna` | `deepseek-flash`；轻量结构化摘要可另测 Flash Lite | 以短文本的成本和可读摘要为目标；失败分类、调用计数和费用应由程序事实提供，不让模型猜测。 |
| `Gemma 4 31B` | 暂不指定首选 | 暂不指定备用 | 缺少用户报价、渠道协议和本项目实测；先核实目标是 Google API 托管调用且具备当前配额，再决定是否纳入对照。 |

`gpt-6.1-Terra` 不因公开的写作定位直接作为默认润色模型；仅作为可比较候选。`gpt-6.1-sol` 不作为所有阶段默认模型，避免在无增益证据时按较高渠道单价扩大成本。最省钱的单位价格模型不自动等于整章总费用最低，也不自动达到可接受的“信”。

## API 配置与人机交互方案

### 配置页面/命令流程

当前仓库只有 CLI 和环境变量/JSON 配置，以下界面属于`计划`，不代表已存在 Web UI。建议先实现 CLI 配置管理/诊断，再依据用户交互需求决定是否开发桌面或 Web UI。

1. **Provider 端点与凭据**：新增/编辑 Provider，填写显示名、协议类型、API URL、可选 API 版本和 Key；Key 输入后显示脱敏状态。自定义 OpenAI-compatible URL 与 Gemini 专用 API URL 应由不同协议类型承载。
2. **模型目录**：添加模型 ID、能力类型（文本生成、封闭决策、嵌入）、所属 Provider、上下文/输出约束（仅在可确认时）、价格来源/更新时间、用户自定义别名。模型类型不匹配时不得被阶段选择器接受。
3. **阶段职责分配**：按职责显示首选模型、备用模型、禁用/仅手动选项；展示来源标签（官方能力、用户渠道价、尚未验证）和切换影响。Embedding 只可分配到嵌入任务，Decision 仅可分配到封闭决策任务。
4. **验证连接**：用户明确触发后发送最小、非书籍内容的测试请求；显示 DNS/TLS/HTTP 状态、鉴权错误、端点不兼容、模型不可用、限流/配额和超时分类。不得在每次保存时自动调用付费 API。
5. **用量/配额**：显示用户录入的参考上限与 API 响应观测到的实际 429/限流信息，分开标注；以每日/每分钟限制、并发/速率状态提示暂停或降速。
6. **保存与回滚**：保存前做配置校验和差异预览；更改首选模型不自动重新处理已完成章节。允许恢复上一个有效配置版本，不保存秘密明文版本。

### 配置数据结构建议（非代码草案）

配置存储按职责拆分以下逻辑对象；实际序列化格式和迁移方式须在阶段 1 确认：

| 对象 | 建议字段 | 敏感性/规则 |
| --- | --- | --- |
| Provider | 稳定 ID、显示名、协议/适配器、API base URL、认证方式、超时、启用状态 | URL 不含 Key；支持自定义端点但限制 URL scheme。 |
| Credential reference | Provider ID、Windows Credential Manager 项标识、Key 最后更新时间/脱敏提示 | 仅引用系统凭据存储，不把 Key 放入 JSON、环境快照、日志、崩溃报告或 Git。 |
| Model | Provider ID、API model ID、显示名/别名、能力类型、用户录入价格、价格币种/单位/来源/更新时间、参考配额 | 未知字段显式为未知；不要由别名推导模型能力。 |
| Stage binding | 阶段 ID、任务类型、primary model ref、fallback model refs、数据授权标签、最大重试/超时、是否启用 | 校验能力匹配、回退协议及输入数据授权。 |
| Usage observation | 日期、Provider/模型、请求/输入/输出/缓存 token、HTTP 状态、限流头/重试提示、估算费用 | 不记录 Key、原文/译文正文；用量以 API 实际返回为准，缺字段为未知。 |

### 安全、校验与故障语义

- Windows 首选 Windows Credential Manager；如未来支持其他 OS，使用对应系统密钥库。禁止将 API Key 明文写入项目 JSON、`.env.example`、日志、命令历史或错误消息；`.env` 仅作为当前兼容开发方式，安全约束见[本地凭据风险记录](security-notes.md)。
- URL 校验要求 scheme、host、端口、路径格式合法；公网 Provider 默认要求 HTTPS。允许 HTTP 仅限显式批准的 loopback 本地服务，并阻止无提示的明文远端请求。当前 OpenAI-compatible 客户端关闭自动重定向，要求配置规范 URL；若后续需要重定向支持，须确保不同 origin 时不携带认证头并增加回归测试。
- 配置校验包含：必需字段、Provider 协议、凭据可用性、model ID、模型能力、生成/嵌入/决策协议匹配、超时与重试范围、主备模型组合和数据授权约束。
- 错误分类至少区分本地配置错误、网络/DNS/TLS、401/403 鉴权/权限、404 模型/路径、400 请求/schema、429 限流/配额、余额/计费限制、5xx 服务端、超时及内容拦截。错误提示提供可操作修复线索，不回显密钥或完整请求头。
- 回退策略需显式配置、有限重试并记录模型切换原因。可对暂时网络错误、429 和部分 5xx 执行受限重试；鉴权失败、错误模型 ID、协议/schema 错误和内容拦截不应盲目重试。跨供应商回退可能重复计费、改变模型行为和发送数据给另一服务商，执行前需逐 Provider 授权。内容拦截仍遵循当前项目终止边界，不通过切换模型规避。
- Gemini 配额不可用静态表格硬编码为账户保证值；用户数字作为带时间戳的参考值，运行时受限作为另一个观测。DeepSeek 时段费用按供应商 UTC 规则计算，并在界面显示用户所在地时区。
- 评估配置导入/导出时，默认排除凭据值。支持用户显式清除凭据引用；不自动撤销服务商 Key。

## 分阶段开发计划

下表使用模型配置工作包 `M0–M6`，与[路线图](roadmap.md)的项目阶段编号不同。它们是后续代码实施的建议任务，不是本次已完成工作；项目路线图状态仍以路线图为准。须先解决项目阶段 0 的端点、数据授权和账户可用性门槛；否则可完成 schema/mock 范围，但不能宣称真实 Provider 或成本/质量验收完成。

### 当前配置与路由基线

- `pipeline.py::get_primary_provider_route` 集中依据模型名前缀把 `sakura`/`sakura-`/`qwen3.6-plus` 路由到 `SAKURA_BASE_URL` 与 `SAKURA_API_KEY`，把 `deepseek-` 路由到 `DEEPSEEK_BASE_URL` 与 `DEEPSEEK_API_KEY`；空白、首尾带空格和不受支持的名称会在章节扫描/客户端创建前拒绝。调用请求与启动 Key 检查共用此映射。该防误路由校验不构成通用 Provider/模型目录或阶段能力配置。
- OpenAI-compatible base URL 在流水线预检和客户端创建处校验：只接受有主机名和有效端口语法的 HTTP(S) URL；公网必须 HTTPS，HTTP 仅限 loopback；拒绝 URL 内认证信息、查询和片段。API Key 继续通过 Provider 专属配置读取。SDK 自动重定向关闭，端点必须提供规范 URL。
- 已修复 `get_base_url` 曾在通用 `CODING_PLAN_BASE_URL` 配置为 loopback 地址或带显式端口 URL 时覆盖上述已选择端点的问题。仓库声明的默认 DashScope URL 没有显式端口；回归测试使用带显式端口的配置复现旧覆盖行为。当前仅测试环境显式设置 `MOCK_SERVER_PORT` 时覆盖为本地 mock URL。
- 当前显式 Gemini 回退仅允许 SDK 连接/超时异常及 HTTP 408/429/5xx；鉴权、请求/schema 错误和内容拦截不触发回退。该本地错误边界由单测和 mock E2E 验证，不构成 Provider 配置、逐阶段绑定、逐数据类别授权或真实服务兼容性验收。
- `API_TIMEOUT` 默认 10 秒且必须是有限正数；当前传入 OpenAI-compatible 聊天和 Gemini 生成、RAG embedding、章节对齐 embedding 调用。Gemini SDK `HttpOptions.timeout` 使用毫秒，由秒值换算；默认值对慢速模型可能过短，须按获准端点实测后由操作者配置。
- `PROVIDER_DATA_POLICY` 已实现为默认空的逐 Provider/数据类别 allowlist，涵盖主请求、Gemini 回退、RAG、章节对齐和知识抽取。类别未全部获准时请求在客户端边界被拒绝；此代码能力不代表任何真实 Provider 或数据类别已被用户授权。
- `CODING_PLAN_BASE_URL`/`CODING_PLAN_API_KEY` 仍在配置类中声明/读取，但没有接入当前主请求路由。用户决定暂不作为独立 Provider 支持，保留未接入配置；不能据此声称已实现 Coding Plan 或可替换 Provider。
- 以上是静态代码与 mock 测试基线；本次未调用真实端点。M1 仍须定义 Provider/模型/凭据/阶段绑定契约，并为当前真实配置建立迁移和兼容规则。

### M6 评测最低规范

- 用户选择按职责分别设定质量门槛，不以单一总分代替所有阶段；具体门槛、预算和默认模型需结合获准样本评测后确定。
- 先明确质量门槛，再评模型；忠实度错误严重度高于流畅度优化。逐章记录模型版本、Provider、提示词版本、参数、数据授权和参考知识快照。
- 对比时固定输入、上下文、温度/推理选项（若协议支持）、段落边界和重试策略；记录失败/拒答，不把失败样本从统计中删去。
- 单价最低但人工修订显著增加的配置，不得仅凭 API 账单判为最优；总成本应包括多阶段调用、回退/重试、嵌入和人工后编辑时间。
- 评测样本及输出留在获准的本地项目存储；外发或上传评测集前须按项目数据政策取得授权。
