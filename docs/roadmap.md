### 方案取舍与用户协助

- 来源与保真：继续使用当前版本化 catalog、逐话归档和双版本/合集契约，可复用既有校验，但不能靠哈希证明语义或版式；替代的人工导入可减少对站点结构的依赖，却不能验证自动采集。近期优先以合成样本补特殊格式与更新场景，再由 AI/工具对已获准试点做可复验格式和语义评估；仅对无可验证标准或结果冲突的项目请求用户判断。
- 知识与审核：沿用人工审核回执可先建立可追溯基线，但审核负担随话数增长，身份与语义仍需核验；风险分层审核 AI 可降低重复工作，却需验证误判和升级机制。先定义来源、风险及未批准隔离，再用获准样本比较效果，不把模型输出自动视为批准。
- 终审与恢复：沿用人工检查和 create-only 发布可防止静默覆盖，但没有评分和自动返工；独立审核 Agent 加有限返工能支持用户目标，却增加调用、费用和错误传播风险。先约定质量硬门槛、返工上限与人工升级，再以合成故障及获准样本验收版本链和发布门禁。
- Provider 与部署：先稳定现有 CLI 和已选渠道的配置契约，投入较小且符合当前单机环境；通用适配器、桌面界面或托管部署可延后，在实际第二渠道需求、用户规模和运维条件明确后再比较。现有 Python 环境和 Pandoc 可执行文件不证明真实 API 或出版部署已就绪。
- 来源：`scripts/ingest_kakuyomu_pages.py --work-url` 和 `scripts/run_kakuyomu_workflow.py --work-url` 可从作品主页发现公开目录，并逐话请求普通 episode URL。实现检查 robots、限速/限大小，不登录、不访问 `/read`；synthetic 目录到 mock 翻译 E2E 验证自动链路。2026-11-15 source-only live run 已归档 88/88，parser v4 保留正文标记，全书 export 已创建。用户明确无需官方澄清；该用户决定不是平台背书或公开分发许可。作者 ZIP 仅供作者账号备份自作小说，与普通读者试点不适用。人工格式验收、真实 Provider 翻译仍未完成，公开计数/checkpoint 不证明草稿/私有话或平台声明外完整性。
- 知识检索：试点需配置审核快照并核对来源；默认未配置时不检索 TM。显式兼容开关可检索完整 TM，但可能引入未审核内容。快照的本地回执也不证明审核者身份或译文正确，完整门禁仍需开发与评估。
- EPUB：现有离线候选构建可提前验证有限结构；正式交付还要补充结构工具和目标阅读器验收，不能仅凭 Pandoc 成功退出判断阅读效果。
