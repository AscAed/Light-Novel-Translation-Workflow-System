## 本轮代码安全验证

- `utils.py` 提供章节直接子文件路径校验和原子文件替换；输入章节拒绝链接路径，译文及知识草稿通过排他新建避免覆盖已有文件。
- `pipeline.py` 的项目目录解析拒绝指向 `projects/` 外部的项目链接，缺失的显式配置文件会立即失败；测试工作区不加载仓库根目录 `.env`。
- 对齐脚本拒绝链接输入，检测损坏/错误 schema 的 TM 而不重置，并在保存前校验 embedding 数量和向量；RAG TM 写入失败会向调用者报告。
- 对应单元测试中，路径组件/绝对路径与普通文件读取用例通过；两个符号链接用例因当前 Windows 用户没有创建符号链接的权限（`WinError 1314`）而跳过。符号链接行为尚未在本机实测。
- Codex Security 自动扫描任务未形成可复核的正式报告：扫描记录接口拒绝了工具生成的草稿字段，未能保存报告。该状态不是扫描通过；需要后续重新运行并取得可审阅报告。

## Provider 安全边界

- `ORIGINAL_REQUEST.md` 的历史方案要求在内容拦截后切换到 Gemini，并为多个类别设置 `BLOCK_NONE`；现行测试已要求内容拦截不得触发跨 Provider 回退。
- 自检保留“内容拦截即停止”的实现边界，删除明确放宽安全阈值的 Gemini 参数，并移除提示模型忽略敏感题材限制的全局指令。普通调用错误仍须由操作者显式开启 Gemini 回退，回退会把同一请求发送给另一 Provider。
- CLI 目前在首个失败章节抛出错误并结束运行；失败章节跳过、继续后续章节和可恢复任务状态尚未实现。相关用户体验见[决策 D-06](decisions/README.md)。
